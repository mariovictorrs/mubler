# Architecture Decision Records

This is where mubler's architectural decisions are recorded. Each ADR is a file named `NNNN-title-in-kebab-case.md`, numbered sequentially, created by copying the [template](0000-template.md).

## Statuses

`Proposed` → `Accepted` → (`Superseded by ADR-NNNN` | `Rejected` | `Deprecated`)

Accepted ADRs are not rewritten; to change a decision, create a new ADR that supersedes it.
